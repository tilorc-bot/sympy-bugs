# NumPyPrinter prints factorial as math.factorial, which fails on floats and arrays

### Kind
crash

### Actual
```pycon
>>> import numpy
>>> from sympy import symbols, factorial, lambdify
>>> from sympy.printing.numpy import NumPyPrinter
>>> k = symbols('k')
>>> print(NumPyPrinter().doprint(factorial(k)))
math.factorial(k)
>>> lambdify(k, factorial(k), 'numpy')(numpy.array([1, 2, 3]))
Traceback (most recent call last):
...
TypeError: only integer scalar arrays can be converted to a scalar index
```

### Expected
```pycon
>>> [float(v) for v in lambdify(k, factorial(k), 'numpy')(numpy.array([1, 2, 3]))]
[1.0, 2.0, 6.0]
```

### Why it is wrong
Functions generated by the NumPy printer are expected to vectorize, but `math.factorial` only accepts a single integer (it also rejects floats such as `3.0`).

### Related
[sympy/sympy#6520](https://redirect.github.com/sympy/sympy/issues/6520)

### Notes on fixing
`sympy/printing/numpy.py` puts `factorial` in `_not_in_numpy`, so `NumPyPrinter` falls back to the `math.factorial` mapping inherited from `PythonCodePrinter`. A vectorized form (e.g. via `gamma(k + 1)` from SciPy, or `numpy.vectorize`) is needed.
